PRIVATE DOCUMENTS — IMAGES SUB-FOLDER
======================================

Put your scanned photo / ID-card style private documents here (JPG/PNG),
kept separate from the PDF files in the parent private-documents/ folder.

Expected file names (used by index.html right now):
1. aadhaar-front.jpg   -> Aadhaar Card front side photo
2. aadhaar-back.jpg    -> Aadhaar Card back side photo
3. passport-photo.jpg  -> Passport-size photo

Each one gets a "View" button (opens in an on-page preview/lightbox) and a
"Download" button on the website automatically — you do not need to edit
any code if you keep these exact file names.

If a file is missing, the button will simply show a broken-image icon when
clicked — just add the correctly named file here to fix it.
