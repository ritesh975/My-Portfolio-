# Ritesh Kumar Portfolio

Responsive personal portfolio built with HTML, CSS and JavaScript.

## Features
- Responsive home page
- View Resume button
- Education section
- Projects with View Demo and View Repo links
- Experience and Internship cards with View options
- Certificate cards with View options
- Contact/social links
- Mobile responsive navigation

## Folder Structure
```text
RITESH-PORTFOLIO/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
├── documents/
├── .gitignore
└── README.md
```

## Run Locally
```bash
py -m http.server 5500
```
Open `http://localhost:5500`.

## Deploy
This is a static website and can be deployed with GitHub Pages, Netlify, Vercel, or other static hosting services.

## Important
Do not upload Aadhaar, marksheets, certificates containing sensitive information, passwords, or other private documents to a public GitHub repository.

## Where to Edit
- Personal details, projects, education, experience and social links: `index.html`
- Design/colors/responsive styling: `css/style.css`
- Menu, animations and interactions: `js/main.js`
- Resume: `documents/`
- Images/certificates: `images/`
